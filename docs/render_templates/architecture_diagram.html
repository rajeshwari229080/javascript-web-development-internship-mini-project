Universal Module Pattern & System Architecture

Clean separation of presentation, business logic, and deterministic test runners

Universal Module Definition (UMD)
🌐 Client Runtime (Browser)
index.html & style.css UI Shell
Accessible dashboard tabs, KPI metrics, dynamic product tables, and form inputs.
↓
js/main.js Controller Events
DOM event orchestration, tab routing, prompt handlers, and virtual console logging.
↓
Virtual Console Logger Telemetry
Captures live system outputs and formats them in real time for interactive inspection.
⚙️ Core Business Logic (ES6+)
Assignments 1 through 6 js/assignment*.js
Standalone modules for variables, operators, grading switch, loops, scopes, and array methods.
↔
js/inventory.js Capstone Engine
Inventory state manager, strict bounds validation, category tier logic, reduce/filter/map pipelines.
↑
Dual Export Hook Compatibility
module.exports for Node.js test runners alongside window.* bindings for browsers.
🧪 Server Runtime (Node.js)
node:test Suite Automated
15 deterministic test cases running across 7 suites without third-party frameworks.
↓
node:assert/strict Contracts
Verifies type integrity, division safety, NaN handling, and expected ReferenceErrors.
↓
CLI Direct Execution Terminal
Run any module directly with node js/assignmentN.js or node js/inventory.js.
